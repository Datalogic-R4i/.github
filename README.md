# .github

Organisation-wide defaults for Datalogic-R4i.

`ISSUE_TEMPLATE/` holds the issue templates every repository uses unless it defines its own: Epic, Story, Task and Bug. Each one puts the new issue on the *Nebula Engineering* board. Blank issues are disabled.

The rules behind them live in the `nebula-engineering` repository (`WORKING-AGREEMENT.md`). Change a template here and in `nebula-engineering/.github/ISSUE_TEMPLATE/` together.
